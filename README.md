# MSP430 임베디드 기말 프로젝트

동국대학교 전자전기공학부 '마이크로프로세서 응용 및 실험'(2024-1) 기말 개인 프로젝트입니다.
TI MSP430 MCU에서 센서, 모터, 키패드, 7-세그먼트를 C로 제어해 4개 과제(추가 문제 포함)를 모두 구현했습니다.

- MCU: TI MSP430
- 언어 / 개발환경: C / Code Composer Studio
- 규모: 문제별 C 소스 4개, 총 약 1,800줄

## 폴더 구성
| 폴더 | 내용 |
|---|---|
| `문제 1` | 랜덤 시간 후 LED 점등 및 반응시간 측정, 7-세그먼트 다이내믹 구동, 엔코더로 남은 바퀴 수(소수점 세자리) 실시간 표시 |
| `문제 2` | ADC 값으로 LED 토글 주기 결정, 키패드로 모터 PWM 가속/감속, 초음파 센서로 장애물 감지 시 모터 정지 |
| `문제 3` | 0.3초 이내 더블클릭 감지, 엔코더로 초기 비밀번호 설정, 키패드 4자리 비밀번호 입력 및 검증 |
| `문제 4` | 비밀번호 입력 후 세그먼트 문자열 표시 및 순환, 10바퀴 회전 카운트, PWM 배열 shift로 정역 교대 회전 |

각 폴더에 `project_N.c`와 문제별 코드 설명 문서가 있습니다. 문제별 구현 과정과 트러블슈팅은 최종 보고서(docx)와 발표자료(pptx)에 정리되어 있습니다.

## 구현 포인트
- **정수 근사 연산**: float 연산 부담을 피하기 위해 1바퀴를 1,000,000으로 두고 엔코더 카운트 1당 1,492씩 빼서 소수점 셋째 자리까지 회전수 계산 (1바퀴 = 670 카운트)
- **모터 정지 판정**: 10ms마다 현재와 이전 엔코더 값을 비교하고, 손으로 멈출 때의 오차를 고려해 차이가 2 이하이면 정지로 판정
- **채터링 제거 두 가지 방식**: 타이머 카운트 방식(문제 2), 버튼 인터럽트 비활성화 후 50ms 뒤 재활성화 방식(문제 3)
